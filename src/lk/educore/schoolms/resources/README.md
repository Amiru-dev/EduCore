# Resources Directory

This directory contains image resources for the EduCore School Management System.

## Icons
Place the following icon files in the `icons/` subdirectory:

- `logo.png` - Application logo (256x256 recommended)
- `profile.png` - User profile icon (64x64 recommended)
- `dashboard.png` - Dashboard icon (32x32 recommended)
- `students.png` - Students module icon (32x32 recommended)
- `teachers.png` - Teachers module icon (32x32 recommended)
- `fees.png` - Fees module icon (32x32 recommended)
- `exams.png` - Exams module icon (32x32 recommended)
- `transport.png` - Transport module icon (32x32 recommended)
- `academic.png` - Academic performance icon (32x32 recommended)
- `finance.png` - Finance module icon (32x32 recommended)
- `events.png` - Events module icon (32x32 recommended)
- `guardians.png` - Guardians module icon (32x32 recommended)
- `library.png` - Library module icon (32x32 recommended)
- `success.png` - Success notification icon (32x32 recommended)
- `error.png` - Error notification icon (32x32 recommended)
- `warning.png` - Warning notification icon (32x32 recommended)
- `info.png` - Information notification icon (32x32 recommended)

## Note
These are placeholder files. Replace them with actual PNG/JPG images for production use.
The SendLogo.java class in the model layer will load these icons using ClassLoader.getResource().

## Icon Specifications
- Format: PNG (recommended) or JPG
- Background: Transparent for PNG
- Size: Various sizes as noted above
- Style: Consistent flat/material design style recommended
